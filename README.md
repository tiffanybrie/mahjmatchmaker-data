# Mahj Matchmaker data

Data behind the Matchmaking Table (Match Builder) on mahjmatchmaker.com.

- `data.json`: Tiffany's hand-styled matches from every color album (tile sets, mats, notes, rack picks).
- `catalog.json`: mats, tile sets and racks from Mahj Matchmaker partner shops, with affiliate links and color tags.
- `config/`: brand list, excluded brands, color fixes.
- `scripts/refresh.sh`: rebuilds both files. Runs every morning.
