## The pattern, and why it keeps happening
- **Checks count the wrong denominator.** gate [90] counts gallery rows in a *config file*, not in the built page; `live_codes_check` skips pages marked "removed" without checking they are gone, only checks hub-linked pages, and only knows 27 brands; the table-view gate checks that walls *work*, not how many sets *have* them.
- **"Done" is declared at the sample.** Walls were confirmed for a 30-set sample; Table view classes were set for the catalog as of Oct 31 and never for later adds; profiles/taglines were written for 1-4 sets.
- **Unattended jobs silently stop.** `device_absent` suspends a task; the cloud catch-up's re-enable step does not take effect, and no chat shows "N tasks are off".
- **Approvals live only in ANSWERS.md.** Nothing counts "approved items with no DONE line older than N days".
