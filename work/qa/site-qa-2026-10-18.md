# Site QA sweep: mahjmatchmaker.com (Oct 18, 2026)

**Scope.** I checked all 114 live pages in the sitemap plus the two new ones (/christmas-mahjong-mats and /blog/holiday-mahjong-table).
- **Widths:** desktop at 1280 and mobile at 390 (iPhone UA), using Playwright Chromium and full-page screenshots.
- **Data checks:** fresh HTML of every page, OCR of 1,597 match cards (956 on Squarespace, 641 on jsDelivr), 996 outbound links, all 801 jsDelivr assets, and a code-rules text scan.
- **Pacing:** 4–8s between page loads. No 429s.
- **No live edits made.** Fixes are staged in `site/livepatch/qa/`.

Screenshots are in `work/qa/shots-2026-10-18/`. The full-page originals and raw data are in the session scratchpad (`qa_oct18/pw/shots`, `results_m.json`, `results_d.json`, `gap390.log`, `gap1280.log`, `linkcheck.log`, `ocr2.json`, `ocr3.json`).

Severity: **High** = visitors see something broken, or it costs money or trust. **Med** = wrong or inconsistent, but usable. **Low** = polish.

### 1. HIGH: Phones show 31,000–41,000px of empty navy below the content on 7 brand guides
- **Pages:** mahj-mood (41,435px blank), yellow-mountain-imports (41,108), splash-of-color (38,864), bam-bird-boutique (36,649), bam-lets-mahjong (33,435), peace-love-mahjong (32,657), amahj (31,492).
- **Smaller gaps:** middle-and-main (9,186), my-fair-mahjong (7,734), sunday-mahjong (4,028), the-mahjong-press (3,335), soiree-all-day (2,063).
- **Color pages:** every color page's block is a fixed 4,329px on mobile. Blank tails: ivory 3,075, brown 2,731, red 2,344, green 1,969, neutral 1,178, yellow-orange 895.
- **What it looks like:** the page ends, then the visitor scrolls through an empty navy screen (about 6–10 phone screens) to reach the footer.
- **Cause:** the single code block keeps a stale Fluid Engine *mobile* row height. Its content is about 6,000px, but the block is 37,000–49,000px.
- **Screenshots:** `01-brand-page-mobile-blank-navy.jpg`, and `13-color-page-blank-tail.jpg` for the color pages.
- **Fix (staged, tested):** `site/livepatch/qa/mobile-codeblock-height.css`.
  - Injecting it on the live page in Playwright took Bam Bird from 43,380px to 6,600px (`10-css-fix-test-brand-page.jpg`). Desktop was unchanged. The home page moved by 120px; re-check it.
  - Alternative without code: in the editor's mobile view on each page, drag the code block's bottom edge up to the content.
- **Desktop:** color pages also carry a 950–1,500px blank tail, from a fixed 2,738px block. Resize the block in the desktop editor.

- **Fix (staged):** `site/livepatch/qa/holiday-rack-lines-v4.json`. It has the corrected linked "Rack matches:" HTML for all 404 cards, built from the manifest at the v4 render commit (ee24b7b), which matches the cards.
